# S2MP-Mod-Bot-Script
A basic script that auto populates bots in public and private matches

Place gsc into Steam\steamapps\common\Call of Duty WWII\S2MP-Mod\scripts\custom

Huge credit to DoktorSAS for creating the initial script this was based off of and Kalitos for helping a lot with the difficulty implementation
Also thanks to Rattpak for making it compatible with S2MP-Mods GSC stuff 

Known Issue: Bot difficulty will reset to regular on round based modes
